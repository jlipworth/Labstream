Labstream is a client for media servers that the user runs or is allowed to use (Plex, Jellyfin, or Emby). It does not include, sell, or subscribe to any media.

For review, use the dedicated Jellyfin review server and non-admin account in the Sign-In Information fields. No personal server or account is needed.

Sign in:
1. Launch Labstream and choose Jellyfin.
2. Enter the server address from the Sign-In Information fields, select Username / Password, enter the username and password, and select Sign in with Jellyfin.

Try the main journey:
1. Open the Libraries tab, then Movies (if a Choose Libraries dialog appears, select Save Selection). Open Spring or Wing It! (open films by the Blender Foundation), then play it from the title's details.
2. Pause, resume, and seek. Leave playback and reopen the same title: its details now offer Resume, and playback continues where you left off.
3. Browse Libraries > Shows (Sample Series > Season 1) and the Music tab.
4. For tracks and chapters, open the Samples library and play Audio and Subtitle Demo, a 30-second sample. Pause it first, then use Subs to turn on English subtitles, Audio to switch between Primary Tone and Alternate Tone, and Chapters to jump between Opening, Passage, and Return. The Sample Series episode has the same tracks.

The review server is a dedicated sample environment with licensed media. Playback progress resets on a schedule, and the server stays available throughout review. Labstream connects directly to the server the user chooses; when that server is on the local network, the app asks for Local Network access.

Apple TV is streaming-only: there are no downloads or offline features on this platform. Navigate with the Siri Remote. The Privacy Policy and Support page are in Settings > About and on the sign-in screen; because Apple TV has no web browser, selecting one shows a QR code and the address.
