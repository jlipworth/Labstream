# DV P5 Guard + Gated True-DV Spikes (#196) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** DV Profile 5 never renders garbage or fails silently on any backend; default-off machinery lands for true DV signalling (dvh1 profile advertising + HLS playlist injection).

**Architecture:** A pure `DolbyVisionPlaybackPolicy` in PMSKit produces a per-stream verdict from the existing `VideoHDRMetadata`. Each backend's request builder gains an explicit force-transcode input driven by that verdict. `PlaybackController` plumbs a "guarded" flag into a first-frame watchdog with a DV-specific error. An experimental preference gates DV profile advertising and `PlaylistRewriter` DV injection.

**Tech Stack:** Swift 6 / PMSKit (swift-testing), SwiftUI visionOS app, existing loopback proxy (`MediaSessionProxy` + `PlaylistRewriter`).

## Global Constraints

- `X-Plex-Client-Profile-Name=Generic` must not change; DV additions go only into `X-Plex-Client-Profile-Extra`.
- Nothing from Goal 1 (spikes) is default-on. The P5 guard IS default-on.
- No tokens, hostnames, media titles, or local paths in committed files or issue comments.
- Never edit pbxproj to add files (file-system-synchronized groups).
- Verify app changes with the CLAUDE.md smoke loop on this worktree's `$SIMID` (clean build; UUID install guard).

### Task 1: `DolbyVisionPlaybackPolicy` (PMSKit)

**Files:**
- Create: `PMSKit/Sources/PMSKit/Models/DolbyVisionPlaybackPolicy.swift`
- Test: `PMSKit/Tests/PMSKitTests/DolbyVisionPlaybackPolicyTests.swift`

**Interfaces:**
- Produces:
  ```swift
  public enum DolbyVisionPlaybackVerdict: Sendable, Equatable {
      case allowCopyLanes
      case forceToneMapTranscode(reason: String)   // reason e.g. "DV P5 guard (no fallback layer)"
  }
  public enum DolbyVisionPlaybackPolicy {
      /// experimentalDVSignallingEnabled: when the user opted into the DV lane, defer (allow).
      public static func verdict(for hdr: VideoHDRMetadata?,
                                 experimentalDVSignallingEnabled: Bool) -> DolbyVisionPlaybackVerdict
  }
  ```
- Rule: force iff `hdr?.dolbyVision != nil` AND (`blCompatibilityID == 0` OR (`profile == 5` && `blCompatibilityID == nil`)) AND `!experimentalDVSignallingEnabled`. Everything else (nil hdr, SDR, HDR10, P7 c6, P8 c1/2/4, unknown profile with compat) allows.

Build each `VideoHDRMetadata` via `VideoHDRMetadata.classify(...)` with a `VideoDolbyVisionInfo` the way the decode tests do.
